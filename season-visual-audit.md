# Season and Cultural Visual Accuracy Audit — August 2026

## Current state

The existing warm-paper field atlas, ledger structures, bilingual context, Solar Ledger, and restrained dark precision panels are sound. The requested pass will extend these systems rather than replace their core layout or calendar logic.

## Confirmed audit findings

| Area | Finding | Direction |
|---|---|---|
| Mobile dock | The dock is compact and present at 375px but needs a subtle active-route transition that feels like a fast field-marker shift, not a generic pill animation. | Add transform/opacity-only cue motion and preserve the neutral crystal material, full 44px targets, and reduced-motion fallback. |
| Alignment | Primary pages use different width rules and a few panels optically drift left on smaller widths. | Introduce a final alignment layer that standardizes page gutters and safely recenters route surfaces without changing information architecture. |
| Brand wordmark | The KA portion is smaller and visually close to the descriptor at some breakpoints. | Strengthen the KA/Festivals hierarchy with the existing display and mono families, not a disconnected new brand system. |
| Solar presentation | The live model works, but the visual phase change can better communicate the handoff from sun to moon. | Add a restrained phase indicator with a moving marker and minimal glow; retain the explicit calculated-orientation scope. |
| Season discovery | Current seasonal context is useful but not available as a dedicated learning route. | Add a Home entry point and a non-primary `/seasons` guide with an India/Indonesia selector, month bands, local labels, and clear “typical pattern, not forecast” language. |
| Festival imagery | Existing visual collections are stable but unevenly specific, especially for generic category fallbacks. | Replace only images for which a credible representative source can be identified; use labelled illustrative context or maintain a fallback rather than implying documentary universality. |

## Visual guardrails

Warm paper remains the dominant reading material. Night-ink surfaces remain dedicated to the solar instrument, selected evidence, and constellation footer. Every added visual must carry an atlas material cue—thread, lamp, calendar scrap, textile, offering, or source label—and all seasonal statements must be framed as broad local patterns rather than live conditions.
