# Discovery visual sources

The rebuilt discovery desk uses respectful, contextual public images from Pexels for three key cultural pathways. They are treated as collection visuals rather than documentary depictions of a single festival celebration.

The fourth card retains a purpose-built CSS textile fallback to avoid falsely representing a specific cultural object and to keep the visual system resilient if a third-party image cannot load.
