# KA Festivals cultural guide research

## Research principles

The interface will describe **typical practices**, not prescribe correct practice. Each short guide must retain a regional/family/community variation note and must not turn a festival date into a claim about observed practice or current travel conditions.

## Source limitations

Some official pages are dynamically rendered or blocked to this environment. Where a primary page could not be read, the product will not infer ceremonial detail from its title/snippet alone. Such festivals receive a cautious, high-level guide based on their existing category and an explicit regional-variation note until a fuller source can be reviewed.

## Implementation boundary

Use a small set of stable direct public image URLs only as **collection visuals**, with `loading="lazy"`, descriptive alt text, and CSS fallback. Do not download a large image archive into the web project, because this static deployment requires lightweight external or managed assets.
