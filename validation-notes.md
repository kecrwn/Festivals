# KA Festivals validation notes

The active preview was tested with the Indonesian and English locale controls. Both controls update the complete shared shell and page copy, retain an explicit `aria-pressed` active state, and persist the selected language for a subsequent reload. The initial missing annual-nav item was traced to a stale preview module state; a cache-busting reload confirmed the rendered shell contains all four routes: Today, Index, Year, and Guide.

The daily companion was opened with `date=2026-08-24`. Switching its country context from All to India and then Indonesia retained the `2026-08-24` date in both the input and URL while refreshing only the country-specific empty state and next celebration. The annual arc was then set to October and switched to Indonesia; it retained October and correctly reduced the list to National Batik Day and Youth Pledge Day.

The discovery route was opened with the documented `query=Diwali` search parameter. It returned the November 2026 Diwali note under a prominent month chapter, while the compact country, year, and category controls remained available. Local browser logs showed no failed application or asset requests; the only recurring console message is the expected development-preview HMR websocket limitation.

Desktop and 375-pixel mobile captures covered Home, the filtered discovery index, the annual timeline, a festival detail page, and the date guide. The home layout condenses the four timezone cards into a readable two-column mobile strip; the festival companion remains small, and the full design uses a non-fixed footer plus a floating mobile dock in normal browsing. The discovery rail becomes a compact stacked context panel, month headers are visually distinct from day rows, and the detail/guide pages preserve their reading hierarchy without horizontal clipping. The preview’s old service worker occasionally retained an earlier header module; the deployed `ka-festivals-v3` policy now uses network-first assets to prevent this returning-visitor issue.

The supplied reference direction was applied as a warm precision-panel system, not as a generic dark dashboard. Fresh desktop and mobile captures confirmed that the new soft glass rails, shallow shadows, exact divider lines, strong date numerals, and dark ink feature panels remain legible on every primary route. At 375 pixels, the home day board, compact time-zone matrix, discovery context rail, month chapters, annual arc, festival story blocks, guide cards, and decorative constellation footer all stack cleanly without horizontal clipping.
